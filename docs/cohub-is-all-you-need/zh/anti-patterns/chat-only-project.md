# 只有聊天的项目

## 为什么有问题

没有持久真相。重启、新 Chat 和协作者都无法重建工作。

## 正确做法

把状态写入**文件**，用 **Save** 标记里程碑，并通过已发布 **App** 分享。

## 嗅探标准

如果关闭 Chat 就会丢失项目，它还不是一个真正的 Space 项目。
