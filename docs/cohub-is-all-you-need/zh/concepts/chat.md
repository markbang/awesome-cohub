# Session

A **Chat** is a conversation context inside a Space. CLI/API name: **session**.

## 实践
- 不同目标用多个 Chat
- 探索替代路径时 Fork；分叉树最多嵌套四层，并带祖先导轨
- `/skill:name` 展开技能；`@space` 有意识地引入跨 Space 上下文
- 使用 Local Runtime 时，可在 Composer 按回合选择 Harness（Pi / Codex）
- 侧栏把 Chat 产出组织为 This chat | Files · Media · Apps
- 跨 Space 收件箱按 Session 来源过滤（`web`、`feishu`、`wechat` 等）
