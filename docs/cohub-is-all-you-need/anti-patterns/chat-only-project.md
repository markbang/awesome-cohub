# Chat-only project

## Why it hurts

There is no durable truth. Restarts, new Chats, and collaborators cannot reconstruct the work.

## Do this instead

Put state in **files**, mark milestones with **Saves**, and share through a published **App**.

## Smell test

If closing the Chat would lose the project, it is not a Space project yet.
