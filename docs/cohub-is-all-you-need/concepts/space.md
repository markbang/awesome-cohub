# Space

A **Space** is the main creative surface in Cohub: Chats, files, Saves, Apps, Tasks, members, channels, and settings in one isolated environment.

## Practice
- One Space ≈ one initiative when possible
- Files are durable truth; Chat is steering
- Configure members/access/channels/mods when collaboration needs it — not on day zero necessarily
- Workspace Markdown can resolve relative image/video/audio assets; keep those files in the Space
- The Apps panel stores installed Apps in `.cohub/apps.json`; Activity summarizes usage and App views without replacing Billing records
- File metadata can include `mtimeMs`, `ctimeMs`, and `isFile` for reliable sync and tooling

## UI vs API
UI: Space · CLI/API: space id + workspace filesystem
