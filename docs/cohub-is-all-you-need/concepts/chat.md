# Chat

A **Chat** is a conversation context inside a Space. CLI/API name: **session**.

## Practice
- Multiple Chats for divergent goals
- Fork when exploring an alternate path; fork trees nest up to four levels with ancestor rails
- `/skill:name` expands skills; `@space` pulls cross-space context deliberately
- With a Local Runtime, choose the Harness per turn (Pi / Codex) from the composer
- The side panel organizes chat outputs as This chat | Files · Media · Apps
- The cross-space inbox filters by session source (`web`, `feishu`, `wechat`, ...)
